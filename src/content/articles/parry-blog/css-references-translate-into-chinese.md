本文分享了我将可视化 CSS References 文档翻译成中文版的介绍，翻译工作还在陆续进行中，供学习 CSS 参考。
<!-- more -->

## 1. 可视化 CSS References 文档介绍
许多 CSS 的文档都是属性的介绍，而开源项目 [css-reference](https://github.com/jgthms/css-reference) 并没有提供中文版，而当我 [分享到社区](http://wxopen.club/topic/583e9c2dbc94e573596844c5) 的时候就有人提出了没有中文版本的问题，刚好自己想过一遍就顺手翻译并在博客域名下部署了一个小站点。

## 2. 文档资源列表
* [英文原站](http://cssreference.io/)
* [英文站点源码](https://github.com/jgthms/css-reference)
* [中文站点](http://cssreference.parryqiu.com/flexbox)
* [中文站点源码](https://github.com/ParryQiu/css-reference)

目前最常用的 Flex 布局部分我已翻译完毕，我也会抽空翻译完剩余的部分。
如果您也想帮忙继续翻译剩余的部分，可以 fork 项目后发送 PR 即可。
