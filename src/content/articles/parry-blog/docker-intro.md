## 2. Docker 简介

> Docker 是一个开源的应用容器引擎，让开发者可以打包他们的应用以及依赖包到一个可移植的容器中，然后发布到任何流行的 Linux / Windows / Mac 机器上，也可以实现虚拟化。
> 容器是完全使用沙箱机制，相互之间不会有任何接口。

简单来说，Docker 提供了一个轻量级的虚拟机服务，你可以快速地通过配置文件（Dockerfile）的形式进行快速地部署，并可以轻松地实现跨平台迁移与部署，这也为后续实现的自动化部署实现了底层技术基础。
