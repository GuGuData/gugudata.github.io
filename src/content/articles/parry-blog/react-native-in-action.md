此文档是我的原创视频课程「80 节实战课精通 React Native 开发」的大纲，供参考查阅。

<!-- more -->

此视频课程是我出版书籍 [《React Native 精解与实战》](《React Native 精解与实战》) 的视频补充部分，基于书籍的文字形式，通过视频进行了项目的实战开发，给你更加直观的学习体验。

书籍的文字部分讲解了大量的 React Native 框架底层原理性的知识，希望大家多多支持我的书籍（即将出版），购买后，你一定会觉得那是一本非常值得购买的书籍。

此课程对 React Native 框架的底层原理、组件、API 以及一些第三方组件进行了实战演示讲解，并结合完整项目的设计、开发、打包与发布，进行了知识点的整合实战学习。

课程地址：[https://devopen.club/course/reactnative](https://devopen.club/course/reactnative)
