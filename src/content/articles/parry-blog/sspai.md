不管是独立开发者还是中小型企业，随着 Web 应用、API 数据接口或者设备越来越多，经常不知道什么时候某一个功能模块宕机了，而等发现宕机的时候可能已经是很多天以后了，如果是一些孵化中产品的话，更是会造成很多种子用户的流失。

咕咕监控通过可配置的监控频率，实现了对站点、接口以及设备的监控，在这些监控的设施设备触发了宕机条件的时候，可以实现 App 消息推送提醒、短信消息提醒等，咕咕监控很快还会开放电话语言提醒以及邮件提醒的功能。

同时应用已支持了 [iOS（iPhone 和 iPad）](https://apps.apple.com/cn/app/%E5%92%95%E5%92%95%E7%9B%91%E6%8E%A7/id1042192962)以及 [Android](https://www.gugujiankong.com/#download) 平台，很快还会发布微信小程序版本，方便用户更加轻量化地接入使用。

## 网站在线监控

对于网站类的连通监控，咕咕监控可以针对站点设置监控频率，在设置的每一个监控频率周期内，咕咕监控将对站点的连通性进行监测，同时还会监测站点的响应时间。

监控的频率可以设置为每隔一分钟、五分钟、十五分钟或一小时监控频率，在检测到不能连通的第一时间将通过设置的通知方式推送消息，以便第一时间进行响应处理，而这样的监控方式是不需要侵入站点服务器，避免了安全相关的问题。

## 接口断言监控

除了用户侧的网站连通性监控外，后端数据接口 API 也需要进行不间断地监测，因为如果后端接口断言失败，按照目前常见的系统架构，可能影响到的不仅仅是网站，很多依赖后端 API 的 App、设备等都可能出现不能访问的情况。

网站类的监控逻辑比较简单，而对于接口 API 类的监控，咕咕监控在设计这部分的时候，不仅仅具有和站点一样通过检测 API 的连通性来判断 API 是否连通，还增加了接口返回值断言的参数设置，方便更加精准地设置 API 连通断言条件。

接口监控支持设置对应的请求方式以及请求参数，并且断言类型支持 Number、String、Bool 以及 JSON 类型，在检测接口返回值的时候进行值相等的判断，进行接口是否正常的断言。

## 设备监控

而对于设备类监控，如服务器、嵌入式硬件等设备，咕咕监控通过 PING 监控响应的形式进行检测，在设置的监测频率周期内出现了不能连通的情况进行消息的即时提醒。

设备的监控同时会在检测次数的基础上记录出最小响应时间、最大响应时间以及平均响应时间，供用户评估设备的健康情况。
