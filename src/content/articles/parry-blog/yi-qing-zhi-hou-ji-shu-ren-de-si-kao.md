整个新年，大多数的我们都在家休了个超长的假期，COVID-19 的疫情总会过去，一个多月的时间，不知大家在家是否有思考自己后续的路应该怎么走，是否应该坚持走下去？

## 幸福的软件研发人员？

我暂且将所有的互联网研发从业人员都统称为软件研发人员。严峻的疫情对我们有影响吗？这里的影响如果只是指研发工作的话，其实严格说起来，很小。

我们有互联网，我们可以远程会议，我们可以躺在床上写代码，我们喜爱的 GitHub 依旧可以顺畅访问，依靠微博我们至少获得了一些新闻与表达的自由。

这也是我一直觉得作为软件研发人员幸福的地方，你基本上只需要一台电脑就可以工作，不分时间、不分地点。

你不用如销售人员一样出去拜访客户，疫情在家就全部停摆。

你也不用如其他行业从业人员一样，受限于疫情的控制，所有的工作都没法推进。

你基本上可以在床上推动整个研发项目的进度，或者穿个睡衣就可以开完一个需求会。

如果 COVID-19 如其他病毒一样，与人类长期共存下去，那么可能会很大程度地改变我们的工作、生活方式，那么你应该趁早思考后续的工作方式、自身的发展方向以及作为一个技术人是否还有一些梦想在坚守着。

## 工作与其他

自身的工作当然要尽职完成，职业道德的部分大家都有自己的思考，这里主要想再次和大家聊聊工作外的东西。

之前我在我们的社区以及微信群里，一直建议大家在空余的时间多多思考、多多动手，做一些自己的业余项目（Slide Project），不管你的目的是做那些小项目学习技术的实现、放在自己的简历里加分，或者为了自己一个小梦想的实现，那怕就是为了写一个赚钱的项目，这些都应该是你用自己的业余时间应该去思考和行动的。

一个公司不仅仅依靠开发人员去持续经营，还会依靠上面提到的销售人员等等相关人员的协作。如果疫情持续下去，你是否有一个自己的项目去赚钱、或者说有一个寄托，每天都可以为它添砖加瓦，持续地去迭代？

这也是我一直鼓励大家去多实现自己的项目，哪怕是搭建一个自己的博客网站、个人的介绍网站等等，都是你应该在这段时间去考虑可以去做的事情。

## 可以的行动

比如这次疫情，你就可以做很多相关的小项目、小工作，不管是为公为私都可以是你行动的动机。

比如你可以在 GitHub 上很容易地获取到此次疫情的数据，你可以使用这些数据进行前端可视化展示、地图可视化展示、实现一个数据查询的小程序、使用 Python 进行数据处理与分析等等工作。

就像我们在群里聊的，学习软件开发技术最大、最高效的方法就是动手，动手，动手。

只有在动手编码的过程中，你才能遇到问题、查询问题、查阅文档、寻找解决问题的思路、总结、提高，达到快速掌握一门技术的目的。
