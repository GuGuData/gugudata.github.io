## 📘 API 文档

### 概览

Promplify API 允许您以编程方式访问您的提示词。此 API 设计简单直观易用。

### 认证

所有 API 请求都需要使用 Bearer token 进行认证。您可以在设置页面生成 API token。

```
Authorization: Bearer YOUR_TOKEN
```

### 端点

#### 获取提示词

```
GET https://api.promplify.com/prompts/{promptId}?version={version}
```

**参数：**

- promptId (路径参数) - 您想要检索的提示词的 UUID
- version (查询参数，可选) - 要检索的提示词的特定版本（例如，"1.0.0"）。如果未提供，则返回最新版本。

**请求头：**

```
Authorization: Bearer YOUR_TOKEN
```

**响应：**

```json
{
  "title": "string",
  "description": "string",
  "content": "string",
  "version": "string",
  "token_count": "number",
  "performance": "number",
  "is_favorite": "boolean",
  "model": "string",
  "temperature": "number",
  "max_tokens": "number",
  "created_at": "string (ISO date)",
  "updated_at": "string (ISO date)",
  "system_prompt": "string",
  "user_prompt": "string",
  "system_tokens": "number",
  "user_tokens": "number"
}
```

**示例：**

获取最新版本：

```bash
curl --location 'https://api.promplify.com/prompts/E72BD69E-A116-497F-94C4-7DE6606A77BE' \
--header 'Authorization: Bearer YOUR_TOKEN'
```

获取特定版本：

```bash
curl --location 'https://api.promplify.com/prompts/E72BD69E-A116-497F-94C4-7DE6606A77BE?version=2.1.0' \
--header 'Authorization: Bearer YOUR_TOKEN'
```

**错误响应**

- 400 Bad Request：Prompt ID is required
- 401 Unauthorized：Authorization header is required 或 Invalid token
- 404 Not Found：Prompt not found
- 405 Method Not Allowed：Only GET requests are supported
- 500 Internal Server Error：An unexpected error occurred
